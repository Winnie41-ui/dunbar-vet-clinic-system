# Dunbar Veterinary Clinic Appointment Management System
ISYS3001 A2 Project

This is a local web application for clinic appointment management.
Runs offline with SQLite local database. No external API or CDN dependencies.

## Clean Checkout Setup
1. Clone this repository
2. Create environment file: copy .env.example to .env
3. Install required dependencies
4. Initialise local SQLite database
5. Run the application
